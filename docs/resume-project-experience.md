# 简历项目经历

## 推荐版本

### AI 产品智能助手（Agentic RAG）｜AI 应用后端开发｜2026.03 - 至今

**项目地址：** https://github.com/ssafdo/ai-product-assistant-rag

**技术栈：** Python / FastAPI / SQLite / React / TypeScript / Agentic RAG / SSE / OpenAI-compatible API / Pytest / GitHub Actions

**项目说明：** 面向产品、销售、售前和客户成功团队构建的企业产品知识助手，将产品手册、价格政策、发布说明和交付 FAQ 转化为可检索知识，提供多轮问答、资料引用、知识库管理和问答链路追踪；支持接入 OpenAI 兼容模型，无 API Key 时可降级为本地有依据回答。

**核心职责与成果：**

- 负责 Python Agentic RAG 主链路设计与实现，基于 FastAPI 串联“问题改写 → 意图路由 → Tool Registry 检索 → GSSC 上下文构建 → 模型路由 → SSE 流式输出”，并兼容 React 问答端与管理后台的 70+ 个接口。
- 建设产品知识入库与治理能力，支持 Markdown、TXT、PDF、DOCX 文档解析、结构感知切分、分块编辑与启停、重新构建和入库日志；首次启动可自动导入 6 份产品样例资料，并使用 SQLite 完成零外部基础设施运行。
- 实现面向中英文查询的加权混合检索，结合术语映射、中文字符/双字词、英文 Token 和意图定向加权完成召回与排序；回答返回 `[资料N]` 引用及命中文档、分块、相关分数和检索通道，降低无依据回答风险。
- 设计会话记忆与上下文预算机制，保留最近 8 条消息并在 10000 字符预算内完成证据筛选、结构化与截断；实现主模型、备用模型和本地有依据回答三级降级，未配置模型服务时仍可完整演示问答流程。
- 建立端到端可观测与工程验证链路，记录问题改写、意图路由、知识检索、上下文构建和模型生成 5 类 Trace 节点，并使用 Pytest 与 GitHub Actions 自动执行 Python 测试和前端生产构建。
