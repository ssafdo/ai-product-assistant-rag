# 发布说明

## 当前版本重点

当前版本重点增强产品资料问答能力，支持更完整的文档入库流程、更清晰的检索链路追踪和更易用的管理后台。

## 新增能力

- 支持产品资料、价格政策、发布说明、竞品分析和客户案例等多类型知识库。
- 支持示例问题配置，便于为销售、售前和客户成功提供常用问法。
- 支持 RAG Trace 查看，帮助管理员定位答案缺失、召回不足和提示词问题。
- 支持关键词映射，例如将“报价”“套餐”“版本权益”统一映射到价格政策相关资料。

## 升级影响

升级后建议重新检查知识库命名、意图树分类和示例问题，确保它们贴合产品业务。旧的企业内务类样例资料可迁移为产品资料、客户案例或交付 FAQ。

## 注意事项

发布说明中的路线图只代表当前计划，不构成对客户的交付承诺。对外承诺必须以合同、订单或正式产品公告为准。
